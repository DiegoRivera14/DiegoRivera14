# Hola, soy Diego Rivera 👋

Desarrollador web junior en formación final del **CFGS en Desarrollo de Aplicaciones Web (DAW)**. Vengo de la automatización industrial y de la electrónica de vehículos eléctricos, y ahora me dedico al desarrollo de software: **Java con Spring Boot** en el servidor y **HTML, CSS y JavaScript** en el navegador.

📍 Galicia, España · 🔎 Busco mi primer empleo como **desarrollador web junior**

## 🚀 Proyecto destacado

### [Paddock F1](https://github.com/DiegoRivera14/paddock-f1)
Aplicación web de consulta sobre la Fórmula 1 (pilotos, escuderías, clasificaciones y calendario), desarrollada como Proyecto de Fin de Ciclo.

`Java` · `Spring Boot` · `Spring Data JPA` · `Spring Security` · `Thymeleaf` · `H2` · `Maven`

Desarrollada con ramas por funcionalidad, Pull Requests y commits con convención (`feat:`, `fix:`, `docs:`).
